# HERO MOTOCROSS 3D

A small Godot 4 mobile motocross prototype with a procedural placeholder motorcycle, simple road scenery, touch controls, keyboard controls, speed HUD and a selectable Hero model-name list.

## Run
Open this folder in Godot 4.3 or later and press Play.

## Android APK
The GitHub Actions workflow in this repository builds a debug APK from this folder. Open the repository's Actions tab, select **Build HERO MOTOCROSS 3D Android APK**, and download the artifact after a successful run.

## Current limitations
This is an early prototype, not a finished commercial racing game. The bike is a simple procedural placeholder; selecting a name changes the HUD label, not the 3D model. It does not contain manufacturer-provided Hero assets, advanced suspension/tyre simulation, traffic, missions, multiplayer, or production audio. Performance and APK export must be tested on a real device.
