# AI ARINDOM SOCIAL

An Android social app starter built with Kotlin and Jetpack Compose.

## Prototype features
- Home feed with sample posts
- Like and unlike posts (local app state)
- Create a text post
- Search screen placeholder
- Profile screen
- Bottom navigation

## Current limitations
This is the first runnable UI prototype. It does **not** yet include real user accounts, cloud photo/video uploads, direct messaging, push notifications, or a server/database. Those require backend services and secure authentication.

## Build an APK
Open the **Actions** tab and run **Build Android APK**, or wait for the workflow to finish after a push. Download the `AI-ARINDOM-SOCIAL-debug-apk` artifact from the successful workflow run.
